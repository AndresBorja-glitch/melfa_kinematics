\# MELFA Kinematics Study Case



Repositorio de estudio para aprender Git, GitHub y modularización de código usando un caso de cinemática de un robot industrial MELFA de 6 GDL.



\## Objetivos



\- Aprender Git y GitHub

\- Organizar un proyecto técnico

\- Modularizar código Python

\- Crear pruebas básicas

\- Versionar avances correctamente



\## Estructura inicial



\- docs/: documentación del caso de estudio

\- notebooks/: notebooks originales

\- src/: código reusable del proyecto
