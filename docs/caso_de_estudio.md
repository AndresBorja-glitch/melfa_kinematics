\# Caso de estudio MELFA



Este proyecto toma un notebook académico de cinemática de un robot MELFA de 6 grados de libertad y lo convierte progresivamente en un repositorio organizado y extensible.



\## Objetivos del caso



\- Aprender Git y GitHub

\- Organizar código técnico

\- Modularizar funciones reutilizables

\- Crear pruebas básicas

\- Publicar avances correctamente
